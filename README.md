## Summary

KnowBridge is a proposed assistant that uses an LLM with RAG over instructor-approved documents to **draft** candidate IF–THEN rules, initial fuzzy-model terms and test cases for student intelligent-systems projects. Every draft is cited or flagged for expert validation; numeric fuzzy parameters are never guessed. After human review, students implement the approved rules in an expert-system or fuzzy tool, and the final system runs **without** the LLM. The pilot uses synthetic data only; sustainability and benefits are hypotheses to be measured, not claims.
